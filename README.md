# TaniConnect

TaniConnect adalah platform marketplace pertanian lokal yang menghubungkan petani dan pembeli, dengan fokus awal pada wilayah Lumajang.

## Tech Stack

### Frontend
- Angular 21
- Tailwind CSS

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT

### Database
- PostgreSQL 18

## Project Structure

- frontend/ - Angular application
- backend/ - Spring Boot application
- docs/ - Project documentation
